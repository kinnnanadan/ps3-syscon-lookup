🔌 Syscon 内部モード（Internal Mode）解析ガイド

UART接続による Syscon 内部診断モードへの移行手順、認証（AUTH）仕様、および内部コマンドのリファレンスです。

【警告・上級者向け情報】ブリック（起動不能）の危険性について
Syscon の内部モードでは、EEPROM の書き換え（w）やチェックサム変更、パッチ適用など、ハードウェア動作の根幹に関わる操作が可能です。誤ったアドレスへの書き込みやチェックサム不整合を起こすと、PS3本体が完全に起動不能（ブリック）になります。
作業前には必ず EEPROM ダンプのバックアップを取得し、すべて自己責任にて実行してください。

1. 外部モード（External）と内部モード（Internal）の違い

PS3 のシステムコントローラ（Syscon）の UART インターフェースには、アクセス権限の異なる2つのモードが存在します。

モード種別 対象基板 概要・できること
外部モード
(External)		 Mullion / Sherwood 共通 通常のUART接続時の初期状態。機能は大きく制限されており、AUTH コマンドによるチャレンジ＆レスポンス認証を通過しないとエラーログ閲覧や起動テストが行えません。
内部モード
(Internal)		 Mullion 系
(COK-001 〜 VER-001)		 Syscon の特定コマンド（eepcsum、r / w によるEEPROM直接読み書き、fantbl による熱制御テーブル編集など）が解放された開発・工場診断用モードです。

2. ハードウェア接続と通信仕様（UART）

PCとマザーボード上の Syscon テストポイントを USB-TTL シリアル変換アダプタで接続します。

  • ロジック電圧: 必ず 3.3V TTL を使用してください（5V を入力すると Syscon IC が即座に破損します）。
  • 配線: 基板の TX ↔ アダプタの RX、基板の RX ↔ アダプタの TX、および GND 同士を接続します（3.3V電源ラインは通常接続不要です）。
  • DIAG ピン（Mullion のみ）: 内部モードを有効化・アクセスする際は、基板上の DIAG ランドを GND に落とした（ショートさせた）状態で主電源スイッチをONにします。
シリアル通信設定 設定値 備考
ボーレート (Baud Rate) 57600 全リビジョン共通（初期の接続確認時は 115200 になる場合あり）
データ / パリティ / ストップ 8bit / None / 1bit 一般的な 8N1 設定
フロー制御 None（なし） XON/XOFF・RTS/CTS ともに無効

3. 代表的な内部モード用コマンド一覧

ps3-syscon-uart 等のスクリプトで AUTH 認証を通過した後に使用できる主なコマンドです。

コマンド 用途・機能 危険度・注意点
errlog エラーログ履歴の表示（最大32件） 安全（読み取り専用）
clearerrlog エラーログ履歴の消去 修理後の動作確認前に使用
bringup 電源投入シーケンスの実行 YLOD発生タイミング・エラー特定に使用
shutdown システムの電源オフ bringup 後の停止に使用
tmp get 0 / 1 現在温度の取得（0: CELL / 1: RSX） 安全（読み取り専用）
fantbl get 0 / 1 現在のファン制御テーブル読み出し 変更前のバックアップ記録に必須
fantbl setini ... ファン制御テーブル（p0〜p9）の書き換え 要注意：書き換え後はチェックサム修正が必要
r [addr] [len] EEPROM / メモリ領域の読み出し 安全（全領域ダンプの取得に使用）
w [addr] [data] EEPROM / メモリ領域への直接書き込み 高危険：40nm換装パッチ等に利用。アドレス誤り厳禁
eepcsum EEPROM チェックサムの検証・再計算 w や fantbl 変更後に不整合がないか確認

🌀 ファン制御値計算（% ⇄ 16進数）

PS3 Syscon のファンPWMデューティ比（0%〜100%）と 16進数制御値（0x00〜0xFF）を相互に変換します（全角入力対応）。

【免責事項・作業上の注意】
ファン回転数を極端に低く設定すると、CELL/RSXのオーバーヒートや熱損傷につながる恐れがあります。また、Sysconへのコマンド送信や熱制御テーブルの書き換えは、記述ミスにより起動不能（ブリック）になるリスクを伴います。数値の設定・コマンド実行はすべて自己責任にて行ってください。

4. 一時ファン固定モード（書き込みなし・電源オフまで有効）

設定: 40% (0x66)
⚠️ ファン固定モードに関する注意（過熱の恐れ）
CELL / RSX の温度テーブル（p0）を上書きして回転数を一時固定します。低すぎる回転数（例: 20〜25%等）のまま高負荷をかけると、温度上昇にファンが追従せず CELL / RSX が過熱・熱損傷する恐れがあります。必ず上の温度監視で実温度を確認しながらご使用ください。
※ fantbl setini ではなく RAM 反映の fantbl set を使用するため、EEPROM への書き込み・eepcsum 修正は不要で、電源を切ると元の設定に戻ります。

                ・電圧が高すぎる場合: 発熱の急増や VRM 過負荷により、CELL / RSX チップや電源回路が永久損傷（焼き付き・故障）する恐れがあります。
